# Graphic Portfolio: Rahul Debnath
1. Images: put files in `images/` (1.jpg, 2.jpg...).
2. Add a design: add `"6.jpg"` or `{ file:"6.jpg", category:"Posters", title:"My poster" }` to `designs` in `script.js`.
3. Name/contact: edit `index.html` (About and Contact sections, title and meta tags).
4. Categories: edit the `categories` array in `script.js`.
5. Netlify: app.netlify.com/drop, drag the whole `graphic-portfolio` folder in. Or push to GitHub, then Netlify > Add new site > Import from Git (no build command, publish directory `/`).
